DataFrame API для Go

gopolars — колонкова бібліотека з eager/lazy виконанням, SQL-планувальником та IO для CSV, JSON, Parquet і IPC. Публічний API зосередений у пакеті github.com/h0rn3t/gopolars/pkg/polars.

Встановлення

Потрібен Go 1.26+. Опційне SIMD-прискорення — через GOEXPERIMENT=simd на AMD64.

go get github.com/h0rn3t/gopolars/pkg/polars
Імпорт: у коді використовуйте аліас polars для зручності — як у прикладах Polars Python.

Швидкий старт

Типовий lazy-пайплайн: scan → filter → group → collect.

package main

import (
    "context"

    "github.com/h0rn3t/gopolars/pkg/polars"
)

func main() {
    io := polars.NewIO()
    df, err := io.ReadCSV(polars.ReadCSVInput{
        Path:      "data.csv",
        HasHeader: true,
        Separator: ',',
    })
    if err != nil {
        panic(err)
    }

    out, err := df.
        Lazy().
        Filter(polars.Col("value").Gt(polars.Lit(int64(10)))).
        GroupBy("city").
        Agg(polars.Sum(polars.Col("value"))).
        Collect(context.Background())
    if err != nil {
        panic(err)
    }
    _ = out
}

df, _ := polars.NewDataFrame(polars.NewDataFrameInput{
    Columns: []frame.SeriesInput{

LazyFrame

Відкладене виконання з pushdown на scan. Завершення — Collect або streaming.

Метод Призначення
Collect(ctx) Materialize у DataFrame
CollectStreaming(ctx, chunkSize) Streaming collect з обмеженою пам'яттю
Explain(optimized) План виконання для діагностики
NewIO().ScanCSV / ScanParquet / … Lazy scan + projection/predicate pushdown
SinkCSV / SinkParquet / SinkIPC Запис без повного materialize в пам'яті 
lf, _ := polars.NewIO().ScanParquet(polars.ScanParquetInput{
    Path: "dataset/**/*.parquet",
})

out, _ := lf.
    Filter(polars.Col("year").Ge(polars.Lit(2020))).
    Select(polars.Col("region"), polars.Sum(polars.Col("amount"))).
    Collect(context.Background())

fmt.Println(lf.Explain(true))

Expr

Вирази для Select, Filter, WithColumns, Agg.

Функція Приклад
Col(name), Lit(v) Колонка та літерал
Sum, Min, Max, Mean, Count Агрегації в GroupBy
When(cond, then, otherwise) Умовні вирази
Namespaces on Expr list_len, str_lower, dt_year, explode, … 
polars.Col("amount").
    Mul(polars.Lit(1.1)).
    Alias("amount_with_tax")

polars.When(
    polars.Col("status").Eq(polars.Lit("ok")),
    polars.Lit(1),
    polars.Lit(0),
)

GroupBy

df.GroupBy(keys...).Agg(exprs...) — eager; lazy через LazyFrame.GroupBy.

result, _ := df.
    GroupBy("region", "year").
    Agg(
        polars.Sum(polars.Col("sales")),
        polars.Mean(polars.Col("margin")),
    )

SQL

NewSQLContext() — реєстрація таблиць і виконання SELECT з CTE, вікнами, set-ops.

ctx := polars.NewSQLContext()
_ = ctx.Register("orders", df)

lf, err := ctx.Execute(context.Background(), `
    WITH top AS (
        SELECT region, sum(amount) AS total
        FROM orders
        GROUP BY region
    )
    SELECT * FROM top WHERE total > 1000
`)
out, _ := lf.Collect(context.Background())
SQLContext
Register / RegisterMany Локальні таблиці
Execute / ExecuteGlobal Запит → LazyFrame
Tables / Unregister Каталог

SIMD (опційно)

AMD64 + Go 1.26+ + GOEXPERIMENT=simd для прискорених Sum/Min/Max на float64.

GOEXPERIMENT=simd go build ./...

Без прапорця — автоматичний scalar fallback з тими самими результатами.
